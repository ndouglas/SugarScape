# GeoSim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reconstruct Cederman's 2003 war-size model as `geosim`, execute the fixed study, and publish source comparisons and modern tail diagnostics with every unavailable result retained.

**Architecture:** One seeded Rust engine owns territorial governments, resource adjustment, conditional front commitments, fighting, structural claims and war clusters. CLI/WASM/web use existing generic adapters; a standalone native recorder exports real engine outcomes and authoritative configurations. Python applies source statistics, whole-history resampling and separate iid tail diagnostics offline.

**Tech Stack:** Existing Rust/serde/rand/PCG and TypeScript/Vite/Vitest; core `libm =0.2.16` with `force-soft-floats`, native-only `sha2 =0.10.9`, CPython3.13.5, NumPy2.4.6 and SciPy1.17.1. `libm` is MIT; `sha2` is MIT OR Apache-2.0; NumPy metadata records BSD-3-Clause AND0BSD AND MIT AND Zlib AND CC0-1.0; SciPy's main license is BSD-3-Clause with distributed build notices. No recovered model or GPL estimator implementation is imported. Survey remains outside the Cargo workspace.

**Spec:** `docs/superpowers/specs/2026-10-03-geosim-design.md`, its linked reading notes, source extraction, artifact audit and premeasurement amendments. Source-only base `4ab07d31fedc7e8f3cf35a36252da71218668fce` is a child of approved-spec commit `d6aeb4e`; it contains corrected source evidence and authored reference probes, without the product engine.
