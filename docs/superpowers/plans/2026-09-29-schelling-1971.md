# Schelling 1971 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Schelling's own 1971 checkerboard the `schelling` model's default (Epstein & Axtell's
1996 variant kept as presets with every difference a named switch), add his one-dimensional line as
a new model kind `line`, and carry both through presets, titles, sweeps, the survey, the page, goldens
and docs.

**Architecture:** `schelling.rs` gains a precomputed neighbor list per site (any neighborhood,
radius and edge rule), per-color demand tables, a nearest-vacancy search and round-by-round
activation, while the random path keeps its class pools and draws, so `vi-*` fingerprints don't move.
A new `line.rs` holds the line model (a `Vec` of colors with insertion moves). Both register in
`model.rs` like the other models.

**Tech Stack:** Rust core, `wasm-bindgen`, the `sugarscape` CLI, TypeScript + Vite + uPlot + Vitest,
the standalone `survey` crate. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-29-schelling-1971-design.md`; rules, claims and page
references in `docs/superpowers/specs/2026-09-29-schelling-reading-notes.md`. Sources:
`papers/schelling/schelling-1971-jms-dynamic-models-of-segregation.pdf` (a scan: read pages as images),
`papers/schelling/schelling-1969-aer-models-of-segregation.pdf`.

## Review Focus

1. **Bounded edges** — a corner square has 3 neighbors and an edge 5 (Moore); a demand is judged
   against the occupied ones only. Pinned in Task 1 by `bounded_corners_and_edges_count_what_is_there`.
2. **Nearest means Manhattan steps, at arrival, with the mover's own square vacated;** ties random;
   on the torus distance wraps. Pinned by `the_nearest_move_takes_the_closest_acceptable_square` and
   `nearest_ties_are_broken_at_random`.
3. **Rounds** — the discontented are listed at the round's start in sweep order; one content at its
   turn stays; one made discontent waits for the next round. Pinned by
   `rounds_skip_the_content_and_defer_the_newly_discontent`.
4. **Demand tables** — the least and most alike wanted for each number of neighbors, per color;
   zero neighbors content under a share, table-governed under a table. Pinned by
   `demand_tables_bound_like_neighbors_both_ways`.
5. **The line's nearest point** — counted in people passed, both directions, insertion between two
   others, the neighborhood truncated at the ends, the reach limit and its fallback. Pinned in Task 2
   by `a_line_mover_inserts_at_the_nearest_point_that_satisfies_it`,
   `the_ends_of_the_line_count_what_is_there` and `a_limited_reach_falls_back_to_the_lesser_demand`.

## Decisions

1. **Old configs without the new fields read as Schelling's rules** (as the norms dominance fix did):
   serde defaults are the literal default. Presets are unaffected.
2. **Stars Red, zeros Blue.**
3. **Congregationists (Fig. 16)** are a table demanding 3 alike at every neighbor count (so fewer than
   3 neighbors is discontent); Schelling's "two out of five, along the edge" is not reproduced and
   the preset says so.
4. **The line wraps for display** at `wrap` people a row (70, a typewriter's margins, p. 152).
5. **One step is one round** under `rounds`, one pass of every agent under `random`.

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Neighborhood { Moore, VonNeumann }
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Edges { Bounded, Torus }
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Movement { Nearest, Random }
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Order { Rounds, Random }
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Sweep { Reading, CenterOut }

/// For each number of occupied neighbors n (index n, 0..=max), the least and
/// most like-colored neighbors wanted; empty uses the agent's share.
#[derive(Clone, Debug, Default, PartialEq, Serialize, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct Demand { pub min: Vec<u8>, pub max: Vec<u8> }
```

`SchellingConfig` gains the ten fields; `Default` becomes Schelling's (width 16, height 13, population
138, preference 0.5/0.5, Moore, radius 1, bounded, nearest, rounds, reading, red_share 0.5, exact
true, empty demands, residence off). `validate()` adds: `radius` 1–3; `red_share` a fraction; each
non-empty demand has `min` and `max` of length `max_neighbors() + 1` with `min[n] ≤ max[n] ≤ n`
allowed to exceed n only in `min` (an unsatisfiable count, used by Fig. 16). `changes()` lists every
new field (all reset-only). `pub fn max_neighbors(&self) -> usize` = Moore (2r+1)²−1, von Neumann
2r(r+1).

Test first:

```rust
#[test]
fn the_default_is_schellings_1971_board() {
    let c = SchellingConfig::default();
    assert_eq!((c.width, c.height, c.population), (16, 13, 138));
    assert_eq!((c.neighborhood, c.radius, c.edges), (Neighborhood::Moore, 1, Edges::Bounded));
    assert_eq!((c.movement, c.order, c.sweep), (Movement::Nearest, Order::Rounds, Sweep::Reading));
    assert!(c.exact && c.preference.min == 0.5);
    let mut e = c.clone();
    epstein_axtell(&mut e);
    assert_eq!((e.width, e.population, e.neighborhood, e.edges), (50, 2000, Neighborhood::VonNeumann, Edges::Torus));
}
```

- [ ] **Step 2: Neighbor lists.** Replace `torus.neighbors` in `tell_neighbors` and `neighbors` with
`adj: Vec<Vec<u32>>` built in `new()` by `fn neighbor_list(c, torus) -> Vec<Vec<u32>>`: for von
Neumann radius 1 on the torus, exactly `torus.neighbors(p)` order (so pool order and draws are
unchanged); otherwise every offset with `0 < |dx|+|dy| ≤ r` (von Neumann) or `0 < max(|dx|,|dy|) ≤ r`
(Moore), row by row, dropping offsets off a bounded board and duplicates on a small torus. `counts`
stay `u8`; `CLASSES` becomes `classes = (k+1)(k+2)/2` for `k = max_neighbors()`, pools a
`Vec` per class. Test:

```rust
#[test]
fn bounded_corners_and_edges_count_what_is_there() {
    let mut w = empty(16, 13); // Schelling's default rules
    put(&mut w, 0, 0, true);
    put(&mut w, 1, 0, true);
    put(&mut w, 0, 1, false);
    put(&mut w, 5, 0, true);
    let corner = w.agent_at(Pos::new(0, 0)).copied().unwrap();
    assert_eq!(w.neighbors(&corner), (1, 2), "a corner sees 3 squares; 2 are occupied");
    assert_eq!(w.adj[w.torus.index(Pos::new(5, 0))].len(), 5, "an edge square has 5 neighbors");
    assert_eq!(w.adj[w.torus.index(Pos::new(5, 5))].len(), 8);
}
```

- [ ] **Step 3: Demands.** `fn content(&self, red: bool, preference: f64, like: u32, occupied: u32) -> bool`:
the color's table when non-empty (`min[n] ≤ like ≤ max[n]`), else `satisfied(like, occupied, preference)`.
`acceptable_classes` takes the same inputs. Every use of `satisfied` for an agent goes through `content`.

```rust
#[test]
fn demand_tables_bound_like_neighbors_both_ways() {
    let mut c = SchellingConfig::default();
    // Fig. 17's integrationists among 8 neighbors: at least 3, at most 6 alike.
    let (mut min, mut max) = (vec![0u8; 9], (0..=8u8).collect::<Vec<_>>());
    min[8] = 3;
    max[8] = 6;
    c.red_demand = Demand { min, max };
    let w = SchellingWorld::new(SchellingConfig { population: 0, ..c }, 1).unwrap();
    assert!(!w.content(true, 0.5, 2, 8) && w.content(true, 0.5, 3, 8));
    assert!(w.content(true, 0.5, 6, 8) && !w.content(true, 0.5, 7, 8));
    assert!(!w.content(false, 0.5, 3, 8), "blue keeps the share: 3 of 8 is under half");
}
```

- [ ] **Step 4: The nearest move.** `fn nearest(&mut self, red: bool, preference: f64, from: usize) -> Option<usize>`:
for d in 1..=(width + height), collect empty squares at Manhattan distance d from `from` (wrapped on
the torus; within the board when bounded) that are `content` for the mover; if any, return one drawn
with `gen_range(0..len as u32)`. The mover's square is already vacated (as in `step`).

```rust
#[test]
fn the_nearest_move_takes_the_closest_acceptable_square() {
    // A red at (0,0) among blues; the only red neighborhood is around (6,6)/(7,6).
    let mut w = empty(16, 13);
    put(&mut w, 0, 0, true);
    put(&mut w, 1, 0, false);
    put(&mut w, 0, 1, false);
    put(&mut w, 6, 6, true);
    put(&mut w, 8, 8, true);
    w.step();
    let red = w.agents().find(|a| a.id == 1).unwrap();
    assert_eq!((red.pos.x, red.pos.y), (7, 7), "the nearest square with at least half red neighbors");
}

#[test]
fn nearest_ties_are_broken_at_random() {
    let spots: std::collections::BTreeSet<_> = (1..40)
        .map(|seed| {
            let mut w = empty_seeded(16, 13, seed);
            put(&mut w, 8, 6, true);
            put(&mut w, 7, 6, false);
            put(&mut w, 9, 6, false);
            put(&mut w, 8, 5, false);
            put(&mut w, 8, 7, false);
            w.step();
            let a = w.agents().find(|a| a.id == 1).unwrap();
            (a.pos.x, a.pos.y)
        })
        .collect();
    assert!(spots.len() > 1, "several equally near empty squares are all chosen sometimes");
}
```

(`empty_seeded` is `empty` with a seed; `put` places an agent of a color with the default preference.
Expected positions in the first test are recomputed by hand while implementing; the assertion is the
Manhattan-nearest square where a red would have at least half red neighbors, with (0,0) vacated.)
