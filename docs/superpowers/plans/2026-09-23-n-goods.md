# N Goods Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the explicit sugar and spice fields with a list of 1–8 goods and a list of 1–4 pollutants, as in the book's own software: N-dimensional Cobb–Douglas welfare, trade over pairs of goods (widest valuation gap first), per-good credit, per-good capacity maps (transforms of the two-peak map, a peaks generator, flat), full pollution matrices, per-good statistics, layers, painting, charts and inspector rows, a Goods editor and a Pollution table — while every existing preset except `vi-1-everything` evolves byte-identically and every legacy config and share link still loads.

**Architecture:** Sites and agents store goods and pollutants in fixed arrays (`[f64; MAX_GOODS]`, `[f64; MAX_POLLUTANTS]`, only slots `0..n` / `0..m` used). `Config` gains `goods: Vec<Good>` and `pollution.pollutants: Vec<Pollutant>`; old JSON (no `goods` key) is read by `src/legacy.rs` and converted inside `Config::from_json`. `econ` gets N-good welfare/MRS proven bit-identical to the two-good forms; each rule is then generalized from its two-slot form to loops over `0..n` whose floating-point order reproduces today's expressions. The world builds each good's capacities from its `Map` (`landscape::generate`) or a supplied per-good array. Statistics, layers, inspection, CSV, the WASM `Sim` and the web UI follow.

**Tech Stack:** Rust (`sugarscape-core`, `sugarscape-wasm`, wasm-bindgen, **js-sys (new)**, rand 0.8, proptest), Vite + TypeScript + uPlot + Vitest.

**Spec:** docs/superpowers/specs/2026-09-23-n-goods-design.md

## Global Constraints

- **Earlier runs are unchanged.** `crates/sugarscape-core/tests/golden.rs` must pass, unedited, at the end of every task — except Task 11 (per-good credit), which re-records exactly the `vi-1-everything` entry with a comment. `tests/legacy.rs` (Task 1) must also pass at the end of every task: every preset's pre-N-goods JSON loads as that preset's config, and a pre-N-goods share link reproduces its recorded fingerprint.
- **Bit-exactness rules** (spelled out again in each task that touches them):
  - *RNG draw order.* Good 0's draws happen where sugar's are drawn today; goods `1..n` draw, in good order, where spice's are drawn today (endowment then metabolism per good in `Agent::random`; metabolism per good in `birth`). No new draws for `n ≤ 2`.
  - *Floating-point order.* Sums over goods start at `0.0` and add in good order; products start at `1.0` and multiply in good order; sums over pollutants start at `0.0` and add in pollutant order. `0.0 + x == x` and `1.0 * x == x` exactly for every value these sums see (none is `-0.0`), and `x + 0.0 * y == x` for finite `y ≥ 0`, so today's expressions are reproduced.
  - *Skipped work.* Work for goods ≥ 1 runs only for goods `< n`, which is exactly where today's code checks `spice.enabled`.
  - *Fingerprint.* `World::fingerprint` hashes, per site, `resource[0], capacity[0], pollution[0]`, then `resource[i], capacity[i]` for `i in 1..n`, then `pollution[k]` for `k in 1..m`; per agent, `holdings[0]` where sugar is hashed today and `holdings[i]` for `i in 1..n` where spice is hashed today; per loan, `good` after `rate` only when `n ≥ 2`.
- **Determinism:** all randomness through `World.rng`; iterate only arrays, `Vec`, `BTreeMap`, `BTreeSet`.
- **Storage:** slots `≥ n` of `Site::resource`/`capacity`, `Agent::holdings`/`initial`/`metabolism`/`income` and slots `≥ m` of `Site::pollution` stay zero in real runs.
- **Tick order is unchanged:** 1. scheduled changes, outbreaks. 2. For each agent (shuffled): move (M or C) → metabolize → [credit income] → death check → S → K → T → L-borrow → E. 3. Settle due loans; growback; diffusion; replacement; aging; stats.
- **Legacy JSON:** `Config::from_json` (and therefore `Sim.new`, `Sim.set_config`, presets exported earlier and share links) accepts both shapes forever; export always writes the new shape.
- **The browser app is not usable from Task 6 until Task 18** (the web UI still reads `config.spice`, `site.sugar`, …). `npm run build` and `npm test` stay green throughout; nobody browser-checks until the controller's puppeteer pass after Task 20.

## Why this task order

The suggested order (rules generalized before the config shape changes) would leave every rule task able to test only `n ≤ 2`, because the old config cannot express three goods. This plan changes the config shape early (Task 6), wiring each rule to the new fields in its existing two-slot form and capping `n ≤ 2` in validation. Tasks 7–11 then generalize one rule at a time with **failing three-good tests** (tests build worlds with `blank_world` and append goods to `world.config` directly, which bypasses validation). Task 12 lifts the cap once every rule handles `n` goods. Maps (Task 4) come before the config change because the converted config needs `Map`.

## Decisions (where the spec leaves room)

These are binding for this plan; each is also stated in the task that implements it.

1. `MAX_GOODS = 8` and `MAX_POLLUTANTS = 4` live in `config.rs`. Legacy colors are `SUGAR_COLOR = "#f2c14e"` and `SPICE_COLOR = "#e07a3f"` (the existing `render::SUGAR`/`SPICE`).
2. A JSON object without a `goods` key is legacy. Detection and conversion happen in `Config::from_json`/`Config::from_value` (code in `src/legacy.rs`); `Deserialize for Config` reads only the new shape (so `with_path` round trips are unaffected).
3. Legacy schedule paths: `metabolism…`/`endowment…` → `goods.0.…`; `spice.metabolism…`/`spice.endowment…` → `goods.1.…`, and such entries are **dropped** when spice was off (they could never have had an effect); `pollution.production`/`pollution.consumption` → `pollution.pollutants.0.{production,consumption}.I` for each polluting good (good 0, plus good 1 when `spice_pollutes`); `pollution.spice_pollutes` and the whole-block `pollution` path are **rejected** (`FieldError` on `schedule`); `spice`, `spice.enabled` and `landscape…` pass through unchanged and fail validation exactly as they did before. A converted change left with no paths is dropped.
4. With `spice_pollutes` on and a coefficient other than 1, `α·g₀ + α·g₁` is not bit-identical to the old `α·(g₀ + g₁)`. No preset uses `spice_pollutes`, so no golden entry moves; such legacy share links may diverge in the last bits (see spec gaps).
5. Reset-only schedule paths: `goods`, `goods.N`, `goods.N.map…`, `pollution`, `pollution.pollutants` (plus the existing disease paths). Schedulable: `goods.N.name`, `.color`, `.metabolism…`, `.endowment…`, and anything under `pollution.pollutants.K`. `structural_changes` reports `goods` (count), `goods.N.map`, `pollution.pollutants` (count); `landscape` and `spice.enabled` are gone from both lists.
6. Validation: good and pollutant names are 1–16 characters and unique within their list; colors are `#` plus six hex digits (either case); a peaks map has 1–16 peaks with centers on the grid, radius finite `> 0`, height `0–10`; map errors use field `goods.N.map` (flat capacity: `goods.N.map.capacity`); rule dependencies: trade and foresight need `n ≥ 2`, combat needs `n == 1`.
7. `rotate_90` turns the map 90° clockwise (north-east peak → south-east); the value shown at `(x, y)` is the base map's value at `Transform::source(x, y)` (table in Task 4). A peak's capacity uses `⌈height·(1 − d/radius)⌉` and is clamped with `if v > 0.0 { v } else { 0.0 }` (so no `-0.0`).
8. MRS's all-zero case tests all `n` metabolisms (at `n = 2` exactly today's test). A pair whose two metabolisms are zero while others are not has a NaN MRS and is skipped.
9. Movement discount: a good devalued by no pollutant (or with pollution off) counts undiscounted; otherwise `d = Σ pₖ` (from `0.0`, pollutant order) and the single-good rule divides, `x / (1.0 + d)`, while the multi-good rule multiplies by the reciprocal, `x * (1.0 / (1.0 + d))` — each is today's expression.
10. `is_fertile` applies the "initial ≤ 0 is excepted" rule to every good including good 0. Today good 0 has no exception, but `is_fertile` only matters for living agents, whose holdings are all `> 0`, so `holdings[0] ≥ initial[0]` already holds whenever `initial[0] ≤ 0`.
11. Credit: the goods a borrower is short of are found before the neighbor shuffle; the shuffle happens iff at least one good qualifies (exactly today's condition at `n = 1`); goods are then borrowed in order over the same shuffled neighbors. `loans_made`, `amount_lent` and `debt_outstanding` total across goods.
12. Trade: "all holdings stay positive" checks every good `0..n` of both agents; the ranking key is `|ln MRS_A − ln MRS_B|`; a stable sort on the descending key keeps `(i, j)` order on ties.
13. `traded_j` for the paying good counts `amount × price`.
14. `World::landscape_edited(good)` compares the good's capacities with its generated map (exactly); it replaces the `landscape_edited` field. Supplied-landscape errors keep field `landscape`.
15. All pollution layers use the existing `POLLUTION` color; pollution chart lines use `--c1…--c4` by pollutant index. `render` returns an error for a layer the world lacks; the web engine falls back to `resource:0`.
16. The WASM crate gains `js-sys` so `Sim.new(config, seed, landscapes)` can take `null`, a `Uint8Array` (legacy: good 0) or an array of `Uint8Array | null`. `series_names_json()` becomes the method `Sim.series_names()` (the names depend on n and m).
17. Share links are written as `{ v: 2, c, s, g?: (string | null)[] }` (per-good base64url maps, `null` for generated ones); `v: 1` links decode with `l` as good 0's map.
18. The agents CSV keeps its 18 columns and appends `holding_I` for each good and `site_pollution_K` for each pollutant; the series CSV follows `stats::series_names`.
19. The fixed `SERIES` list gains `trade_pairs` (24 names); `series_names(config)` appends `mean_holding_I, mean_metabolism_I, traded_I` per good, then `mean_pollution_K` per pollutant.
20. In the web UI, adding a good switches combat off and removing down to one good switches trade and foresight off (so the edit is valid). `AgentOverrides.metabolism`/`sugar` keep applying to good 0.

```rust
//! Configs and share links saved before N goods still load and run
//! unchanged. The fixtures were written by this file's (since deleted)
//! `write_legacy_fixtures` before any N-goods change; never regenerate them.

use std::collections::BTreeMap;

use sugarscape_core::config::Config;
use sugarscape_core::presets;
use sugarscape_core::world::World;

const ALPHABET: &[u8; 64] = b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_";

fn base64url_encode(bytes: &[u8]) -> String {
    let mut out = String::new();
    for chunk in bytes.chunks(3) {
        let b = [chunk[0], *chunk.get(1).unwrap_or(&0), *chunk.get(2).unwrap_or(&0)];
        let v = (u32::from(b[0]) << 16) | (u32::from(b[1]) << 8) | u32::from(b[2]);
        for k in 0..=chunk.len() as u32 {
            out.push(ALPHABET[((v >> (18 - 6 * k)) & 63) as usize] as char);
        }
    }
    out
}

fn base64url_decode(text: &str) -> Vec<u8> {
    let (mut out, mut acc, mut bits) = (Vec::new(), 0u32, 0u32);
    for c in text.bytes() {
        let v = ALPHABET.iter().position(|&a| a == c).expect("base64url character") as u32;
        acc = (acc << 6) | v;
        bits += 6;
        if bits >= 8 {
            bits -= 8;
            out.push((acc >> bits) as u8);
            acc &= (1 << bits) - 1;
        }
    }
    out
}
```

Why they are bit-identical at n = 2: `m_T = (0.0 + m₀) + m₁` and `0.0 + m₀ == m₀` for `m₀ ≥ 0` (metabolisms are `u32 + fee·k` with `fee ≥ 0`, never `-0.0`), so `m_T` equals today's `m₁ + m₂`; the exponents are the same divisions; the zero case is `1.0 / 2.0 == 0.5` exactly; the product is `(1.0 · A) · B` and `1.0 · A == A` (A is `max(w, 0)^a`, never NaN). MRS is the same expression with `(w[j]·m[i]) / (m[j]·w[i])`. At n = 1 with `m₀ > 0`, today's `welfare(w₀, w₁, m₀, 0)` is `w₀^1 · w₁^0 = w₀^1 · 1.0`, and `welfare_n` is `1.0 · w₀^(m₀/(0.0+m₀)) = w₀^1`.

```rust
/// Exponents mᵢ/m_T over n goods (1/n each when every metabolism is zero).
/// m_T is summed from 0.0 in good order, so for two goods it is exactly
/// m₁ + m₂ and the exponents equal `weights`'.
fn weights_n(m: &[f64]) -> [f64; MAX_GOODS] {
    let total = m.iter().fold(0.0, |sum, &x| sum + x);
    let mut out = [0.0; MAX_GOODS];
    for (slot, &x) in out.iter_mut().zip(m) {
        *slot = if total > 0.0 {
            x / total
        } else {
            1.0 / m.len() as f64
        };
    }
    out
}

/// Book eq. 1 over n goods: W = Π wᵢ^(mᵢ/m_T), negative holdings counting as
/// 0; the product starts at 1.0 and multiplies in good order.
pub fn welfare_n(w: &[f64], m: &[f64]) -> f64 {
    let a = weights_n(m);
    w.iter()
        .zip(a)
        .fold(1.0, |product, (&x, e)| product * x.max(0.0).powf(e))
}

/// Book eq. 6 over n goods: welfare as if `phi` periods of each metabolism
/// were already spent.
pub fn foresight_welfare_n(w: &[f64], m: &[f64], phi: u32) -> f64 {
    let phi = f64::from(phi);
    let mut spent = [0.0; MAX_GOODS];
    for ((slot, &x), &mi) in spent.iter_mut().zip(w).zip(m) {
        *slot = x - phi * mi;
    }
    welfare_n(&spent[..w.len()], m)
}

/// MRS for goods i < j: (wⱼ·mᵢ)/(mⱼ·wᵢ), units of j worth one unit of i
/// (book eq. 3 at (0, 1)); wⱼ/wᵢ when every metabolism is zero.
pub fn mrs_n(w: &[f64], m: &[f64], i: usize, j: usize) -> f64 {
    if m.iter().all(|&x| x == 0.0) {
        return w[j] / w[i];
    }
    (w[j] * m[i]) / (m[j] * w[i])
}
```

```rust
        Transform::Rotate270,
        Transform::MirrorX,
        Transform::MirrorY,
        Transform::Transpose,
        Transform::AntiTranspose,
    ];

    /// The base-map cell shown at (x, y) on a w×h map (w = h for the
    /// two-peak map).
    pub fn source(self, x: usize, y: usize, w: usize, h: usize) -> (usize, usize) {
        match self {
            Transform::Identity => (x, y),
            Transform::Rotate90 => (y, h - 1 - x),
            Transform::Rotate180 => (w - 1 - x, h - 1 - y),
            Transform::Rotate270 => (w - 1 - y, x),
            Transform::MirrorX => (w - 1 - x, y),
            Transform::MirrorY => (x, h - 1 - y),
            Transform::Transpose => (y, x),
            Transform::AntiTranspose => (h - 1 - y, w - 1 - x),
        }
    }
}
```

```rust
/// Row-major capacities of `map` on a width×height torus (row 0 = north).
/// `TwoPeaks` is only valid at 50×50 (enforced by `Config::validate`).
pub fn generate(map: &Map, width: u32, height: u32) -> Vec<f64> {
    let (w, h) = (width as usize, height as usize);
    match map {
        Map::TwoPeaks { transform } => {
            let base = capacities(&LandscapeKind::TwoPeaks, width, height);
            (0..w * h)
                .map(|i| {
                    let (x, y) = transform.source(i % w, i / w, w, h);
                    base[y * w + x]
                })
                .collect()
        }
        Map::Peaks { peaks } => (0..w * h)
            .map(|i| peak_capacity(peaks, i % w, i / w, w, h))
            .collect(),
        Map::Flat { capacity } => vec![*capacity; w * h],
    }
}

/// The highest ⌈height·(1 − d/radius)⌉ over `peaks` (0 where all are ≤ 0).
fn peak_capacity(peaks: &[Peak], x: usize, y: usize, w: usize, h: usize) -> f64 {
    let torus = |a: usize, b: u32, n: usize| {
        let d = (a as f64 - f64::from(b)).abs();
        d.min(n as f64 - d)
    };
    peaks
        .iter()
        .map(|p| {
            let (dx, dy) = (torus(x, p.x, w), torus(y, p.y, h));
            let v = (p.height * (1.0 - (dx * dx + dy * dy).sqrt() / p.radius)).ceil();
            if v > 0.0 {
                v
            } else {
                0.0
            }
        })
        .fold(0.0, f64::max)
}
```

```rust
fn is_under(path: &str, root: &str) -> bool {
    path == root || path.strip_prefix(root).is_some_and(|rest| rest.starts_with('.'))
}

/// The new paths a legacy schedule path sets (Decision 3); empty when the
/// entry could have had no effect.
fn convert_path(path: &str, n: usize, spice_pollutes: bool) -> Result<Vec<String>, FieldError> {
    if is_under(path, "metabolism") || is_under(path, "endowment") {
        return Ok(vec![format!("goods.0.{path}")]);
    }
    if let Some(rest) = path.strip_prefix("spice.") {
        if is_under(rest, "metabolism") || is_under(rest, "endowment") {
            return Ok(if n >= 2 { vec![format!("goods.1.{rest}")] } else { Vec::new() });
        }
    }
    for field in ["production", "consumption"] {
        if path == format!("pollution.{field}") {
            let polluting = if spice_pollutes { n } else { 1 };
            return Ok((0..polluting)
                .map(|i| format!("pollution.pollutants.0.{field}.{i}"))
                .collect());
        }
    }
    if path == "pollution" || path == "pollution.spice_pollutes" {
        return Err(FieldError::new(
            "schedule",
            format!("{path} can no longer be scheduled; schedule pollution.enabled or pollution.pollutants.0.… instead"),
        ));
    }
    Ok(vec![path.to_string()])
}
```

```rust
//! Agent trade rule T (Chapter IV) over pairs of goods. With each neighbor,
//! in random order: rank the pairs i < j by |ln MRS_A − ln MRS_B| (widest
//! first; ties to the lowest (i, j)) and make one exchange on the first pair
//! that passes the book's checks — the agent valuing good i more buys it with
//! good j at p = √(MRS_A·MRS_B), 1 of i for p of j if p ≥ 1, else 1/p of i
//! for 1 of j — as long as both agents' welfare over every good strictly
//! rises, their MRSs for the pair don't cross, and every holding stays
//! positive; then re-rank. Pairs with a non-finite, non-positive or equal
//! MRS are skipped. With two goods this is the book's loop.
```
```rust
use crate::config::MAX_GOODS;
use crate::econ::{mrs_n, welfare_n};

#[derive(Clone, Copy)]
struct Holdings {
    n: usize,
    w: [f64; MAX_GOODS],
    m: [f64; MAX_GOODS],
}

impl Holdings {
    fn of(world: &World, id: AgentId) -> Self {
        let n = world.config.goods.len();
        let fee = world.config.disease.active_fee();
        let a = world.agent(id).expect("live agent");
        Self {
            n,
            w: a.holdings,
            m: std::array::from_fn(|i| if i < n { a.effective_metabolism(i, fee) } else { 0.0 }),
        }
    }

    fn welfare(&self, w: &[f64; MAX_GOODS]) -> f64 {
        welfare_n(&w[..self.n], &self.m[..self.n])
    }

    fn mrs(&self, w: &[f64; MAX_GOODS], i: usize, j: usize) -> f64 {
        mrs_n(&w[..self.n], &self.m[..self.n], i, j)
    }
}

/// A pair of goods whose valuations differ: (i, j, MRS_A, MRS_B).
type Pair = (usize, usize, f64, f64);

/// Pairs i < j with finite, positive, unequal MRSs, widest
/// |ln MRS_A − ln MRS_B| first (a stable sort keeps (i, j) order on ties).
fn ranked_pairs(ha: &Holdings, hb: &Holdings) -> Vec<Pair> {
    let mut pairs: Vec<(f64, Pair)> = Vec::new();
    for i in 0..ha.n {
        for j in i + 1..ha.n {
            let (ma, mb) = (ha.mrs(&ha.w, i, j), hb.mrs(&hb.w, i, j));
            if ma.is_finite() && mb.is_finite() && ma > 0.0 && mb > 0.0 && ma != mb {
                pairs.push(((ma.ln() - mb.ln()).abs(), (i, j, ma, mb)));
            }
        }
    }
    pairs.sort_by(|x, y| y.0.total_cmp(&x.0));
    pairs.into_iter().map(|(_, pair)| pair).collect()
}

/// One exchange on `pair` if the book's checks pass; returns whether it
/// happened.
fn exchange(world: &mut World, (a, ha): (AgentId, &Holdings), (b, hb): (AgentId, &Holdings), pair: Pair) -> bool {
    let (i, j, ma, mb) = pair;
    let p = (ma * mb).sqrt();
    let ((buyer, hbuy), (seller, hsell)) = if ma > mb {
        ((a, ha), (b, hb))
    } else {
        ((b, hb), (a, ha))
    };
    let (qi, qj) = if p >= 1.0 { (1.0, p) } else { (1.0 / p, 1.0) };
    let mut buy = hbuy.w;
    buy[i] = hbuy.w[i] + qi;
    buy[j] = hbuy.w[j] - qj;
    let mut sell = hsell.w;
    sell[i] = hsell.w[i] - qi;
    sell[j] = hsell.w[j] + qj;
    let n = hbuy.n;
    let positive = buy[..n].iter().chain(&sell[..n]).all(|&x| x > 0.0);
    let better = hbuy.welfare(&buy) > hbuy.welfare(&hbuy.w)
        && hsell.welfare(&sell) > hsell.welfare(&hsell.w);
    let no_cross = hbuy.mrs(&buy, i, j) >= hsell.mrs(&sell, i, j);
    if !(positive && better && no_cross) {
        return false;
    }
    world.agent_mut(buyer).expect("buyer").holdings = buy;
    world.agent_mut(seller).expect("seller").holdings = sell;
    world.events.trades.push(Trade {
        buyer,
        seller,
        goods: (i, j),
        price: p,
        amount: qi,
    });
    true
}

pub(crate) fn trade_pair(world: &mut World, a: AgentId, b: AgentId) {
    for _ in 0..MAX_EXCHANGES {
        let (ha, hb) = (Holdings::of(world, a), Holdings::of(world, b));
        let pairs = ranked_pairs(&ha, &hb);
        if !pairs
            .into_iter()
            .any(|pair| exchange(world, (a, &ha), (b, &hb), pair))
        {
            return;
        }
    }
}
```

```rust
/// How much of `good` agent `a` may lend now.
pub(crate) fn lendable(a: &Agent, good: usize) -> f64 {
    let (have, born_with) = (a.holdings[good], a.initial[good]);
    if a.age > a.fertility_end {
        (have / 2.0).max(0.0)
    } else if fertile_age(a) && have > born_with {
        have - born_with
    } else {
        0.0
    }
}

/// Σ(amount due / the loan's own duration) over `id`'s loans of `good`.
fn obligations(world: &World, id: AgentId, good: usize) -> f64 {
    world
        .loans()
        .filter(|l| l.borrower == id && l.good == good)
        .map(|l| l.due / f64::from(l.duration))
        .sum()
}

/// Sets each good's income = gathered − effective metabolism − per-tick
/// obligations in that good.
pub(crate) fn record_income(world: &mut World, id: AgentId, harvest: &Harvest) {
    let n = world.config.goods.len();
    let fee = world.config.disease.active_fee();
    let owed: [f64; MAX_GOODS] =
        std::array::from_fn(|i| if i < n { obligations(world, id, i) } else { 0.0 });
    let a = world.agent_mut(id).expect("live agent");
    let income: [f64; MAX_GOODS] = std::array::from_fn(|i| {
        if i < n {
            harvest.gathered[i] - a.effective_metabolism(i, fee) - owed[i]
        } else {
            0.0
        }
    });
    a.income = income;
}

/// A fertile-aged agent short of its birth endowment of some goods, with
/// positive income in them, asks its neighbors (shuffled once) for each such
/// good in good order.
pub(crate) fn borrow(world: &mut World, id: AgentId) {
    let c = world.config.credit;
    let n = world.config.goods.len();
    let me = world.agent(id).expect("live agent");
    let short: Vec<usize> = (0..n)
        .filter(|&i| fertile_age(me) && me.holdings[i] < me.initial[i] && me.income[i] > 0.0)
        .collect();
    if short.is_empty() {
        return;
    }
    let d = f64::from(c.duration);
    let mut neighbors = world.torus.neighbors(me.pos);
    neighbors.shuffle(&mut world.rng);
    for good in short {
        let me = world.agent(id).expect("live agent");
        let mut need = me.initial[good] - me.holdings[good];
        let mut capacity = me.income[good] * d / (1.0 + c.rate / 100.0 * d);
        for &q in &neighbors {
            if need <= 0.0 || capacity <= 0.0 {
                break;
            }
            let Some(lender) = world.occupant(q) else {
                continue;
            };
            let amount = lendable(world.agent(lender).expect("occupant"), good)
                .min(need)
                .min(capacity);
            if amount <= 0.0 {
                continue;
            }
            world.agent_mut(lender).expect("lender").holdings[good] -= amount;
            world.agent_mut(id).expect("borrower").holdings[good] += amount;
            world.originate_loan(lender, id, good, amount);
            world.events.loans_made += 1;
            world.events.amount_lent += amount;
            need -= amount;
            capacity -= amount;
        }
    }
}

/// Settles loans due this tick, oldest first, each in its own good.
pub(crate) fn settle(world: &mut World) {
    let due: Vec<_> = world
        .loans()
        .filter(|l| l.due_tick == world.tick)
        .map(|l| l.id)
        .collect();
    for loan_id in due {
        let loan = world.remove_loan(loan_id).expect("due loan");
        let available = world
            .agent(loan.borrower)
            .expect("borrowers' loans die with them")
            .holdings[loan.good];
        // Paying in full must leave the borrower alive (holding > 0);
        // otherwise it pays half and the rest rolls over.
        let paid = if available > loan.due {
            loan.due
        } else {
            available / 2.0
        };
        world.agent_mut(loan.borrower).expect("borrower").holdings[loan.good] -= paid;
        world
            .agent_mut(loan.lender)
            .expect("lenders' loans die with them")
            .holdings[loan.good] += paid;
        if paid < loan.due {
            world.originate_loan_on(
                loan.lender,
                loan.borrower,
                loan.good,
                loan.due - paid,
                loan.duration,
                loan.rate,
            );
            world.events.defaults += 1;
        }
    }
}
```

```rust
    pub fn paint_capacity(
        &mut self,
        x: u32,
        y: u32,
        radius: u32,
        value: f64,
        good: usize,
    ) -> Result<(), String> {
        let center = self.checked_pos(x, y)?;
        if good >= self.config.goods.len() {
            return Err(format!("there is no good {good}"));
        }
        if !(value.is_finite() && value >= 0.0) {
            return Err("capacity must be ≥ 0".into());

        for dy in -r..=r {
            for dx in -r..=r {
                if dx * dx + dy * dy > r * r {
                    continue;
                }
                let site = self.site_mut(self.torus.offset(center, dx, dy));
                site.capacity[good] = value;
                site.resource[good] = site.resource[good].min(value);
            }
        }
        Ok(())
    }
```

```rust
pub enum Layer {

    Pollution(usize),

    fn from_str(s: &str) -> Result<Self, String> {
```

```rust
const ALPHABET: &[u8; 64] = b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_";

fn base64url_decode(text: &str) -> Vec<u8> {
    let (mut out, mut acc, mut bits) = (Vec::new(), 0u32, 0u32);
    for c in text.bytes() {
        let v = ALPHABET.iter().position(|&a| a == c).expect("base64url character") as u32;
        acc = (acc << 6) | v;
        bits += 6;
        if bits >= 8 {
            bits -= 8;
            out.push((acc >> bits) as u8);
            acc &= (1 << bits) - 1;
        }
    }
    out
}
```

```rust
/// Per-good landscapes from JS (Decision 16): null/undefined → none; a
/// Uint8Array → good 0's (a pre-N-goods share link); an array → one entry per
/// good, each a Uint8Array or null.
fn landscapes_from_js(value: &JsValue) -> Result<Vec<Option<Vec<f64>>>, JsValue> {
    let bytes = |v: &JsValue| -> Vec<f64> {
        js_sys::Uint8Array::new(v)
            .to_vec()
            .into_iter()
            .map(f64::from)
            .collect()
    };
    if value.is_null() || value.is_undefined() {
        return Ok(Vec::new());
    }
    if value.is_instance_of::<js_sys::Uint8Array>() {
        return Ok(vec![Some(bytes(value))]);
    }
    if js_sys::Array::is_array(value) {
        return Ok(js_sys::Array::from(value)
            .iter()
            .map(|v| {
                if v.is_null() || v.is_undefined() {
                    None
                } else {
                    Some(bytes(&v))
                }
            })
            .collect());
    }
    Err(field_errors(vec![FieldError::new(
        "landscape",
        "expected null, a Uint8Array or an array of Uint8Array | null",
    )]))
}
```

```ts
  const wire: Wire = { v: 2, c: state.config, s: state.seed };
  if (state.landscapes?.some((l) => l !== null)) {
    wire.g = state.landscapes.map((l) => (l ? bytesToBase64Url(l) : null));

export async function decodeShare(token: string): Promise<ShareState> {
  try {
    const json = await inflateCapped(base64UrlToBytes(token));
    const wire = JSON.parse(new TextDecoder().decode(json)) as Partial<Wire>;
    if (
      (wire.v !== 1 && wire.v !== 2) ||
      typeof wire.s !== 'number' ||
      typeof wire.c !== 'object' ||
      wire.c === null ||
      Array.isArray(wire.c)
    ) {
      throw new Error('not a SugarScape share link');
    }
    // A v1 config is in the pre-N-goods shape; the WASM side converts it.
    const state: ShareState = { config: wire.c, seed: wire.s >>> 0 };
    if (wire.v === 1 && typeof wire.l === 'string') state.landscapes = [base64UrlToBytes(wire.l)];
    if (wire.v === 2 && Array.isArray(wire.g)) {
      state.landscapes = wire.g.map((x) => (typeof x === 'string' ? base64UrlToBytes(x) : null));
    }
    return state;
  } catch {
```

```ts
import type { Config, Good, GoodMap, Peak, Pollutant, Transform } from './types';

export const MAX_GOODS = 8;
export const MAX_POLLUTANTS = 4;
export const MAX_PEAKS = 16;

/** Two-peak transforms, in the order new goods take them (the book's sugar, then spice). */
export const TRANSFORMS: [Transform, string][] = [
  ['identity', 'As in the book'],
  ['mirror_x', 'Mirrored left↔right'],
  ['rotate_90', 'Rotated 90°'],
  ['rotate_180', 'Rotated 180°'],
  ['rotate_270', 'Rotated 270°'],
  ['mirror_y', 'Mirrored top↔bottom'],
  ['transpose', 'Transposed'],
  ['anti_transpose', 'Anti-transposed'],
];

/** Colors new goods take, first unused first (sugar's and spice's lead). */
export const PALETTE = ['#f2c14e', '#e07a3f', '#7fb3d5', '#8fcf6b', '#c58fd6', '#e0d06a', '#6ad0c4', '#d67a8f'];

function unusedName(taken: string[], stem: string, from: number): string {
  let k = from;
  while (taken.includes(`${stem} ${k}`)) k++;
  return `${stem} ${k}`;
}

export function newPeak(config: Config): Peak {
  return {
    x: Math.floor(config.width / 2),
    y: Math.floor(config.height / 2),
    radius: Math.max(1, Math.floor(Math.min(config.width, config.height) / 4)),
    height: 4,
  };
}

/** A map of `kind`: the next unused two-peak transform (flat off the 50×50 grid), one central peak, or flat 2. */
export function defaultMap(config: Config, kind: GoodMap['kind'] = 'two_peaks'): GoodMap {
  if (kind === 'peaks') return { kind: 'peaks', peaks: [newPeak(config)] };
  if (kind === 'flat' || config.width !== 50 || config.height !== 50) return { kind: 'flat', capacity: 2 };
  const used = new Set(config.goods.flatMap((g) => (g.map.kind === 'two_peaks' ? [g.map.transform] : [])));
  const transform = TRANSFORMS.map(([t]) => t).find((t) => !used.has(t)) ?? 'identity';
  return { kind: 'two_peaks', transform };
}

export function newGood(config: Config): Good {
  const colors = new Set(config.goods.map((g) => g.color.toLowerCase()));
  return {
    name: unusedName(config.goods.map((g) => g.name), 'good', config.goods.length + 1),
    color: PALETTE.find((c) => !colors.has(c)) ?? PALETTE[config.goods.length % PALETTE.length],
    map: defaultMap(config),
    metabolism: { min: 1, max: 4 },
    endowment: { min: 5, max: 25 },
  };
}

/** Appends a good; every pollutant gets zero coefficients for it. Combat needs one good, so it switches off. */
export function addGood(config: Config): void {
  if (config.goods.length >= MAX_GOODS) return;
  config.goods.push(newGood(config));
  for (const p of config.pollution.pollutants) {
    p.production.push(0);
    p.consumption.push(0);
    p.devalues.push(false);
  }
  config.combat.enabled = false;
}

/** Removes good `i` (never the last one) and its pollutant columns; trade and foresight switch off below two goods. */
export function removeGood(config: Config, i: number): void {
  if (config.goods.length <= 1 || i < 0 || i >= config.goods.length) return;
  config.goods.splice(i, 1);
  for (const p of config.pollution.pollutants) {
    p.production.splice(i, 1);
    p.consumption.splice(i, 1);
    p.devalues.splice(i, 1);
  }
  if (config.goods.length < 2) {
    config.trade.enabled = false;
    config.foresight.enabled = false;
  }
}

export function newPollutant(config: Config): Pollutant {
  const n = config.goods.length;
  const names = config.pollution.pollutants.map((p) => p.name);
  return {
    name: unusedName(names, 'pollutant', names.length + 1),
    production: Array<number>(n).fill(0),
    consumption: Array<number>(n).fill(0),
    devalues: Array<boolean>(n).fill(false),
  };
}

export function addPollutant(config: Config): void {
  if (config.pollution.pollutants.length < MAX_POLLUTANTS) config.pollution.pollutants.push(newPollutant(config));
}

export function removePollutant(config: Config, k: number): void {
  const list = config.pollution.pollutants;
  if (list.length > 1 && k >= 0 && k < list.length) list.splice(k, 1);
}
```

```rust
/// Standard deviation across living agents of ln MRSᵢⱼ (disease is off in
/// these presets, so effective metabolism is the genetic one).
fn ln_mrs_spread(w: &World, i: usize, j: usize) -> f64 {
    let n = w.config.goods.len();
    let logs: Vec<f64> = w
        .agents()
        .filter_map(|a| {
            let m: Vec<f64> = a.metabolism[..n].iter().map(|&x| f64::from(x)).collect();
            let v = econ::mrs_n(&a.holdings[..n], &m, i, j);
            (v.is_finite() && v > 0.0).then(|| v.ln())
        })
        .collect();
    let mean = logs.iter().sum::<f64>() / logs.len() as f64;
    (logs.iter().map(|x| (x - mean).powi(2)).sum::<f64>() / logs.len() as f64).sqrt()
}
```

## Spec gaps and conflicts found

1. **`spice_pollutes` arithmetic.** The spec's pollutant `[α, α]` gives `α·g₀ + α·g₁`, not today's `α·(g₀ + g₁)`; they differ in the last bits unless α = 1. No preset is affected (Decision 4); legacy links with the flag and α ≠ 1 may diverge.
2. **Legacy `pollution.spice_pollutes` (and whole `pollution`) schedule paths** have no counterpart in the conversion rules; this plan rejects them (Decision 3). Legacy `spice.*` trait paths with spice off are dropped.
3. **Movement formula.** The spec writes `xᵢ / (1 + Σ p)`; today's two-good rule multiplies by the reciprocal. Keeping each form where it is used today (Decision 9) is required for bit-exactness.
4. **"CSV exports append one column per good and per pollutant"** is ambiguous for the agents CSV (agents hold goods, sites hold pollutants): resolved by Decision 18.
5. **Pollutant colors** and the placement of `trade_pairs` in the series list are unspecified (Decisions 15 and 19).
6. **`n-2-pollutants`** doesn't say whether trade is on; this plan leaves it off (the spec lists only pollution and diffusion).
